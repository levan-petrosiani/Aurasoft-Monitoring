Requirements drafted from the standards. A draft only counts once a person approves it; every action is recorded with the reviewer's name. The quote of each rule was checked against the clause text by the tool; warnings below a rule are for the reviewer.

How to review

The tool has already checked that each quote is in the standard (green line). You check what it means:

  1. Does the quote say what the requirement says? Nothing added. The English line is an AI translation (მმპ = app, ამსმპ = bank).
  2. Is it a duty of the bank? Not a description of a request, an example, or a duty of the app or customer.
  3. Is the level right? MUST = must / shall / აუცილებელია · SHOULD = should / უმჯობესია · MAY = may / optional / "if this function is supported" / შეიძლება. An orange warning means: look closely.
  4. One thing, visible from outside? "When the app sends X, the bank returns Y."
  5. New? Check any "possible duplicate" it names.

All fine → Approve. Small fix → Edit, then approve. Not a bank duty or wrong → Reject with a reason. Unsure → leave it as a draft. Full guide with examples: docs/ai/REVIEW-GUIDE.md.
