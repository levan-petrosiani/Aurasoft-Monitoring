Test scenarios drafted by AI from approved rules. The tool set the id, the rule link and the spec reference, loaded each draft with the engine and ran it on an in-process MockBank (never a real bank). A draft becomes a file in scenarios/ only when you approve it.

How to review a scenario
  1. Does it test the rule, and only the rule? Read the rule above the YAML, then the steps: what is sent, what is expected.
  2. Is the request otherwise valid? For a negative test only the one field the rule is about should be wrong.
  3. Are the expectations the rule's? Status and error code as in the rule. An orange note means they differ.
  4. Dry run. Passed = MockBank behaves as the rule says. Failed with a "MockBank gap" note = the model thinks the scenario is right and MockBank does not implement the rule; check the failing step (e.g. MockBank answered 201 where the rule says 400). If you agree, approve: the scenario will fail on MockBank until MockBank is fixed, and test real banks correctly.

Small fix → Edit the YAML (checked and dry-run again on save). Wrong idea → Reject with a reason. Details: docs/ai/REVIEW-GUIDE.md.
